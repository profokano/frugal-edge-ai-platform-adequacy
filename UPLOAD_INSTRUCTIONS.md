# Upload via GitHub web browser

1. Open <https://github.com/profokano/frugal-edge-ai-platform-adequacy> and sign in.
2. Click **Add file** → **Upload files** (or **uploading an existing file** for an empty repository).
3. **Extract the ZIP on your computer first.** Do not upload the ZIP as a single file: the intended repository consists of its folders and individual files.
4. Open the extracted `frugal-edge-ai-platform-adequacy` folder, select its contents (including `scripts`, `derived`, `results`, `metadata`, and the documentation files), then drag them into the upload area. GitHub may not preserve hidden `.gitignore` via all browser drag/drop methods; add it separately if necessary.
5. Check that paths and folders are preserved and that no dataset images, model binaries, credentials, or private documents are selected.
6. Use a commit message such as `Add research scripts, results, and documentation`, then choose **Commit changes**.
7. Open the repository page and verify `README.md`, `scripts/`, `derived/`, `results/` and `metadata/` are visible.
8. **Do not create a GitHub Release or Zenodo deposit yet** until the public uploaded content is reviewed. Add a license only after confirming that publication and redistribution rights are appropriate.

A Zenodo DOI does not exist at the time of preparing this ZIP.
