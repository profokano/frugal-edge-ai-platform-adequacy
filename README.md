# Frugal Edge AI Platform Adequacy — Research Artifacts

Supporting scripts, selected logs, derived tables, and model integrity metadata for the manuscript **“A Frugal Edge AI Framework for Context-Specific Platform Adequacy in Resource-Constrained Digital Applications”** (MDPI *Digital*, manuscript ID `digital-4631576`).

This repository supports inspection and partial reproduction of the reported methods. It is **not** a complete self-contained reproduction environment: original datasets, trained weights/HEF binaries, and some historical training/calibration records are not included.

## Contents

| Directory | Materials |
|---|---|
| `scripts/` | CPU-only ONNX Runtime benchmarking, HailoRT inference, COCOeval checks, and Kolektor mask-to-box conversion |
| `derived/` | PAS/SAW/TOPSIS comparison table and image-level bootstrap summary |
| `results/hailo_benchmark/results/` | Selected benchmark logs, settings, AP validations, image-level counts, and detector predictions |
| `metadata/hef_sha256.json` | Checksums of four model binaries **not included** in the repository |
| `metadata/manifest_sha256.txt` | SHA-256 hashes of the distributed files (excluding the manifest itself) |

## Experiment protocols — do not pool results

* **CPU-only ONNX comparison:** six boards were evaluated historically at 640 × 640 pixels. The six-device observations are not a single synchronized campaign. Accelerator hardware was not used in this protocol. The values in `derived/Digital_Etapa2_MCDM_resultados.csv` reflect reported, rounded Figure 3 measurements, not recovered raw per-inference logs for all six devices.
* **Hailo-8L accelerator studies:** 416 × 416 pixels, DeepPCB and KolektorSDD2, a **different protocol** from the CPU-only platform scoring. Do not directly combine Hailo metrics with the CPU-only PAS table.
* **Accuracy:** the archive includes custom 101-point AP results and available `pycocotools` COCOeval validation. The `summary.json` custom AP fields do not alone constitute official COCOeval. Consult per-run `cocoeval_validation.json` when available.
* **Statistical intervals:** the `derived/` bootstrap table contains 4,000 image-level resamples for operational precision/recall/F1; it does **not** provide uncertainty for AP/mAP or independently retrained models.

## Data sources

Original dataset images are **not redistributed**. Obtain them from their original providers and follow their licenses and terms:

* [DeepPCB](https://github.com/tangsanli5201/DeepPCB)
* [KolektorSDD2](https://www.vicos.si/resources/kolektorsdd2/)

For the Hailo evaluations, the source files were arranged as `datasets/DeepPCB_yolo/images/test`, `datasets/DeepPCB_yolo/labels/test`, and corresponding KolektorSDD2 test image/label folders. The original local paths in archival JSON records were replaced with relative paths for publication. **No KPI values or detector predictions were changed.** This sanitization means the original full-byte hash manifest from the earlier private archive does not apply; a new public-file manifest is supplied.

## Environment and requirements

* Python 3 and `numpy`, `opencv-python` for processing; `pycocotools` for COCO validation.
* ONNX CPU benchmarking additionally requires `onnxruntime` and `psutil`.
* Hailo scripts additionally require a compatible **HailoRT / `hailo_platform`** installation, Hailo-8L hardware, matching HEF binaries, and original dataset files. The archive's Hailo runs used HailoRT 4.24.0; the environment is hardware-specific and cannot be installed using the generic `requirements.txt` alone.

Install generic packages with `python -m pip install -r requirements.txt`, using a compatible Python and platform. HailoRT is installed separately according to the vendor's instructions.

## Script usage

Read each script's `--help` output for actual options. Example to validate already-exported DeepPCB predictions after obtaining the dataset:

```bash
python scripts/validar_coco_deeppcb_corrigido.py \
  --images datasets/DeepPCB_yolo/images/test \
  --labels datasets/DeepPCB_yolo/labels/test \
  --results-root results/hailo_benchmark/results/deeppcb_e2e
```

ONNX benchmark (requires the corresponding model and test dataset, not included):

```bash
python scripts/edgeai_onnx_benchmark.py --help
```

The `derived/` files are archived analytical outputs; the original source archive did **not** include end-to-end scripts for recalculating every PAS/SAW/TOPSIS or bootstrap row. Do not describe these tables as automatically regenerated by the listed benchmark scripts.

## Scope and limitations

Only datasets and model identifiers required to interpret released results are included. Model binaries and training checkpoint files are not redistributed. SHA-256 digests are provided for HEF artifact identification, but cannot substitute for model availability. Deployment thresholds must be interpreted against their defined application profile. The available benchmark timestamps and CPU measurements do not establish a synchronized head-to-head hardware evaluation. Cost and power consumption were not quantified in these results.
